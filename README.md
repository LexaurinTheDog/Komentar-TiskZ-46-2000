# Komentář k zákonu č. 46/2000 Sb., o právech a povinnostech při vydávání periodického tisku a o změně některých dalších zákonů (tiskový zákon)

Otevřený komentář k tiskovému zákonu — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; odpovědnost vydavatele, evidence periodického tisku, povinné údaje a výtisky, právo na odpověď a dodatečné sdělení, doplňující informace, ochrana zdroje a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2000-00046_2025-07-01`.
